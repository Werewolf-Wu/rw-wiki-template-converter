CreatureInfobox 中文转换器

把英文站的信息框代码转成雨世界灰机 Wiki 的中文调用。

粘贴一个完整的 {{CreatureInfobox …}}，然后点击“转换”。
0 字符

也可按 Ctrl + Enter（Mac 为 ⌘ + Enter）转换。只粘贴一个模板，不要粘贴整篇文章。

尚未转换

生成的代码需要本站已部署的相应模块、模板和样式。红链不代表转换失败，离线工具不能确认线上文件与页面是否存在。

    补充名称对应

    填写您确认的中文名称或站内文件名后，点击重新转换。每个转换器的输入、结果和对应关系单独保留，仅在本次打开期间有效，不会写入词典。种间关系的名称还必须由站内数据模块识别，网页补充对应不会修改站内数据。

    CreatureInfobox 转换范围与使用注意
    • 处理当前中文模板的47个参数。保留代码名称、数值、伤害倍率、地图链接及参数顺序，不根据游戏常识补写刷新数据。
    • 支持角色列表、10类地区参数，以及常见的 Head、NoHead、Unlock|Sandbox、DLC标记。复杂或未收录模板保留原文并提示，不保证在灰机可用。
    • 源模板的 version、地区中的旧DLC标记等不能直接套用到中文接口。遇到这些内容，请按提示整理，不要直接发布。
    • 目前仅内置拾荒者展示图的已核实英文到中文文件名对应。其他图片保留原值供核对，不能通过翻译文件名来代替上传文件。
    • 没有给出 name 时，工具没有原页面标题可供推断。请确认目标页面的默认名称是否合适。
    • 饱食格的 1/1 per Needle-Spearmaster 会转成 1/每根针获得1格-矛大师，不会当作分数运算。
    • 只提供代码转换，不预览或执行维基模板。转换后仍应在站点沙盒检查。手动修改右侧结果后，不要再次转换，除非希望重新生成。
    种间关系转换范围与使用注意
    • 把默认关系转成 默认=，十二种关系键和生物名称转成中文；保留权重和列表次序。
    • DLC 的值使用“任意”“倾盆大雨”“观望者”，多个值用英文逗号分隔。含义仍是最低内容需求，不是隐藏其他版本生物的筛选开关。
    • 目标站须部署中文输入版 Relationships。旧英文调用也需同步转换，不能仅替换模块。
    • 未知项保留并提示，冲突和结构错误会阻止转换。没有正式中文名的项目保留规范名称，不编造译名。输出不计算或改写生物关系。
